# BOXPACK

Адаптивная главная страница BOXPACK по предоставленному макету. Проект использует Next.js App Router, TypeScript и Tailwind CSS.

## Запуск

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

Откройте http://localhost:3000.

## Проверка production-сборки

```bash
npm run build
npm run start
```

Основная разметка находится в `app/page.tsx`, глобальные стили — в `app/globals.css`.
